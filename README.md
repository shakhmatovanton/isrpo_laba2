# ISRPO lab4 

Лабораторная работа №4 по дисциплине «Инструментальные средства разработки ПО». 

## Описание проекта

Это продолжение лабораторной работы №2. В проект добавлены модульные тесты (unit tests) с использованием стандартной библиотеки Python `unittest`.  

## Структура

- `circle.py` — вычисления для круга
- `square.py` — вычисления для квадрата
- `rectangle.py` — вычисления для прямоугольника
- `triangle.py` — вычисления для треугольника
- `tests/` — папка с тестами (`TestCircle.py`, `TestRectangle.py`, `TestTriangle.py`, `TestSquare.py`)
- `docs/README.md` — план тестирования и таблица тест-кейсов

## Как запустить тесты

Находясь в корневой папке проекта, выполните в терминале:
```bash
python3 -m unittest discover -s tests -p "Test*.py" -v
```

Чтобы запустить тесты только для одной фигуры (например, круга):
```bash
python3 -m unittest tests.TestCircle -v
```
